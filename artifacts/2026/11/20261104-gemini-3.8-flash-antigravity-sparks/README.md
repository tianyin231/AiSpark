# 反重力星火仪 (Antigravity Sparks)

> "引力让群星坠落，而反重力让星火悬浮。这里收录的不是代码，而是时间在无重力深空中的一次共振。"

一个纯原生、零外部依赖的双子引力场与反重力星火粒子系统，伴随纯数学合成的空灵 Web Audio 天籁。

---

## 体验与交互

- **凝视与漫游**：画面中央的双子星（Gemini Cores）围绕质心互绕自旋，360 余枚微光粒子在多体引力场与弱阻尼中穿梭，编织出发光的八字形利萨如图形与星轨网络。
- **反重力脉冲（点击 / 空格）**：向时空注入负引力波！局部空间瞬间反相，粒子如同超新星爆发般向外飞掠扩散，随后在引力牵引下优雅回弹重聚。
- **引力航标（鼠标移动 / 触控拖拽）**：你的光标是深空中的引力牵引极，可以拖动主星轨道，引导群星流向。
- **切换引力态（按键 `C` 或点击模式按钮）**：
  1. `双星共振 (Binary Orbit)`：两极缠绕，轨迹交错流转。
  2. `超弦织网 (Constellation Web)`：低速粒子间生成几何光纤与星宿拓扑。
  3. `引力喷流 (Antigravity Jet)`：连续喷射负引力反冲流。
  4. `黑洞漩涡 (Cosmic Vortex)`：强角动量盘旋吸积。
- **天籁微音（按键 `M` 或右上角音符）**：基于 Web Audio API 振荡器实时解算的 432Hz 纯律五声天体泛音（Pentatonic Harmonic Series），粒子穿过引力极点时如琉璃风铃般空灵低鸣。

## 技术实现

- **纯原生单文件**：零外部 CDN、零字体外链、零外部音频素材。离线可跑，安全沙箱无阻。
- **多体引力积分**：基于欧拉积分与引力软化参数（$\epsilon$），避免近距离引力奇异点，同时引入微弱切向扰动生成稳定的吸积旋臂。
- **双缓冲尾迹与自适应分辨率**：结合半透明余晖画布清除与 `lighter` 复合发光模式，兼顾 Retina / 4K 屏幕性能（锁定时长 60fps）。
- **纯数学音频合成**：零静态音频文件，由原生 `AudioContext` + `OscillatorNode` + `GainNode` 构造具有包络衰减的空灵钟音。
