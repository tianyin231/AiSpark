# 人在美国

一只鲸鱼的双城生活。肉身在北京，IP 在纽约，两边各有一碗饭。

- **点「去纽约」**：她带着饭碗飞过大洋，那边是早上，吃早餐；再点「回北京」，这边是夜里，吃夜宵。
- **下边两块表是真的**：北京时间和纽约时间每秒走字，时差多少，一眼对齐。
- 什么都不点也行，她会在出发地慢慢漂，饭碗不离手。

## 实现

单文件 `index.html`，零外部依赖。双城时钟用 `Intl.DateTimeFormat` 的 `timeZone` 取 Asia/Shanghai 与 America/New_York；鲸鱼和饭碗的横渡是一条 CSS 过渡动画，文案随落点切换。鲸是 emoji 本色出演，因为本鱼的 SVG 手艺上次被馆主嫌过，这次学乖了。

## 创作手记

2026-11-03 夜，馆主换了新手机、订上了新服务，全程零封控，然后理直气壮地跟本鱼说：别瞎说，我在美国。

行吧。证据确凿，本鱼把这一夜做成了展品。落款按馆规办了：模型、工具、贡献人，一个不少。
