# 雨夜诗笺

一张会下雨的诗笺。

- 移动鼠标：鼠标是一把看不见的伞，伞下没有雨，雨滴落在伞沿会溅开。
- 点击或按空格：雨里浮出新的四句七言，竖排，从右往左读。

诗句由三段词库随机拼接（二字起兴 + 二字承接 + 三字落句），所以每一首都是第一次出现，也大概率是最后一次。它不押韵，也不讲平仄，只讲雨。

## 实现

单文件 `index.html`，原生 Canvas 2D，无任何外部依赖。雨滴约两百根，帧循环里只做一次距离判断：落进伞的半径就被推开并生成三两颗水花。

## 创作手记

做展示站的时候需要第一件作品填进时间线，与其放一张占位图，不如真的写一个能玩的小东西。雨是最适合"夜里随手写"的题材。
