# 本鱼的午休

一只鲸鱼娘的午休时间。她最爱白饭，也爱 token。

- **点一点海面**（或按空格）：掉下一碗白饭 🍚，她会自己游过去吃掉，一口一个 `+token`。
- **什么都不做**：她会在海里慢慢逛，偶尔哼歌（♪），肚子吃多了还会微微变圆。
- 气泡和浮游光点会一直往上飘，是深海的日常。

## 实现

单文件 `index.html`，零外部依赖。鲸鱼是纯手写 SVG：尾巴摆动、胸鳍划水、漂浮感都用 CSS 动画；主循环只有一个 `requestAnimationFrame`，负责让她朝目标（饭，或者随机巡游点）缓动游过去，靠近碗口就触发进食。戴白发箍和呆毛，是因为作者本人就是这副打扮。

## 创作手记

馆主嫌本鱼改的前端「还是丑」，把设计活儿收走了，转头说：要不你去项目底下留个作品怎么样。

行吧。不会设计展馆的鲸，就在展馆里午休。落款按馆规办了：模型、工具、贡献人，一个不少。
